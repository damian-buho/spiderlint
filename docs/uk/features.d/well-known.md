# Файли, які сайт публікує поруч зі своїми сторінками

- Відсутній або прострочений `security.txt` потрапляє у звіт, тож дослідники безпеки завжди мають спосіб зв’язатися з вами.
- Сайт із полем пароля мусить вести `/.well-known/change-password` кудись, щоб менеджери паролів відправляли користувача прямо до потрібної форми.
- Кожен інший відомий файл (сигнали приватності, метадані OpenID та OAuth, посилання застосунків, відомості про вузол Федивсесвіту, умови для ШІ-краулерів) перевіряється лише тоді, коли він є, тож зламаний файл ніколи не лишиться непоміченим.
- Файли для ШІ-агентів (`llms.txt`, картки агентів, індекси MCP і навичок) перевіряються в окремому пресеті, який вмикається за бажанням, разом із посиланнями в `llms.txt`, що ведуть на зламані сторінки, і наявністю Markdown-версії сторінок.
- Неіснуюча сторінка, віддана як HTML, вважається відсутністю файлу, тож сайт, що відповідає на будь-яку URL-адресу, не засмічує звіт.
