# Вага зображень виміряна, а не оцінена

- Кожне зображення, яке завантажує сайт, перекодовується один раз, і повідомляється, скільки байтів заощадили б AVIF, WebP або щільніше кодування у власному форматі.
- Кожне важке зображення — це одна знахідка зі сторінками, що його використовують, по всьому сайту, а не на вибірці сторінок.
- Зображення, що передають значно більше пікселів, ніж показують, або не мають ширини й висоти для резервування місця, позначаються для кожного шаблону.
- Виміри кешуються разом із зображенням, тож повторний запуск вимірює лише те, що змінилося.
