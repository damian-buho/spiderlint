# robots.txt читається так, як його читають краулери

- Про robots.txt, що закриває весь сайт для всіх краулерів, повідомляється, бо він прибирає сайт із результатів пошуку.
- ШІ-краулери, яких він називає, перелічуються за призначенням — навчання, пошук чи запит користувача — із позначкою тих, кого він блокує, і назв, яких жоден постачальник уже не надсилає.
- Повідомляється про Content Signals, що кажуть щось інше, ніж yes чи no, для пошуку, входу ШІ або навчання ШІ.
