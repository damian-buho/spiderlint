# Структуровані дані й розмітка перевіряються на кожній сторінці

- У звіт потрапляють структуровані дані в JSON-LD, Microdata чи RDFa, які не розбираються, не мають того, чого вимагає їхній розширений результат, суперечать сторінці чи решті сайту, містять застарілі терміни schema.org, хибно записані чи суперечливі дати, або чиї хлібні крихти ведуть на відсутні чи переміщені сторінки.
- Маніфест вебзастосунку перевіряється на те, що потрібно для встановлення сайту: назву, стартову сторінку, режим відображення та іконки розмірів, яких просять телефони.
- Розпливчасті тексти посилань на кшталт «натисніть тут» шукаються мовою самої сторінки, а мова без перевіреного списку пропускається, а не оцінюється за англійськими мірками.
