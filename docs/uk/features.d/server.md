# Сервер перевірок

- Той самий образ працює як HTTP API з чергою завдань і як вебсторінка, де будь-хто вводить домен і читає звіт англійською, іспанською чи українською, з JavaScript або без нього.
- Кожна перевірка показує свій поступ під час роботи, її звіт завантажується в усіх форматах, які видає командний рядок, а сайт може показувати свою останню оцінку значком із посиланням на звіт.
- Власник екземпляра задає політики для доменів: заборонити домен верхнього рівня, обмежити частоту перевірок хоста, обмежити сторінки й час і вибрати, які правила можна запускати. Повторний запит у межах заданого вікна повертає вже зроблену перевірку, а кожен клієнт має власний ліміт.
- Політики перечитуються зі змонтованого файлу без перезапуску.
- Перевірку не можна спрямувати на локальні чи приватні адреси або на адреси хмарних метаданих.
