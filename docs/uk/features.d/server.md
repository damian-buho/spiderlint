# Сервер перевірок

- Той самий образ працює як HTTP API з чергою завдань, тож команда чи будь-хто може замовити аудит, нічого не встановлюючи.
- Кожна перевірка показує свій поступ під час роботи, а її звіт завантажується в усіх форматах, які видає командний рядок.
- Власник екземпляра задає політики для доменів: заборонити домен верхнього рівня, обмежити частоту перевірок хоста, обмежити сторінки й час і вибрати, які правила можна запускати.
- Політики перечитуються зі змонтованого файлу без перезапуску.
- Перевірку не можна спрямувати на локальні чи приватні адреси або на адреси хмарних метаданих.
