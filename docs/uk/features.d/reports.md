# Звіти для людей, конвеєрів і агентів програмування

- Знахідки виводяться як текст, JSON, SARIF, Checkstyle, CSV чи HTML-звіт, а збережений обхід переформатовується без повторного звернення до сайту.
- Формат agent перетворює знахідки на завдання виправлення для агента програмування, впорядковані за серйозністю й за тим, скільки сторінок виправляє кожна правка.
- Дія CI перевіряє сайт на кожен push, завершує завдання з помилкою на обраній серйозності, вивантажує SARIF в аналіз коду й кешує обхід, тож повторна перевірка незміненого сайту майже нічого не коштує.
- Коди виходу відрізняють знахідки від хибної конфігурації та від недосяжного сайту, тож конвеєр знає, що саме не вдалося.
