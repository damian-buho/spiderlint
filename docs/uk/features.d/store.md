# Один обхід — багато перевірок

- Обхід можна зберегти на диску й перевірити знову зі зміненими правилами чи групами без доступу до мережі.
- Перерваний обхід продовжується з місця зупинки.
- Бінарні файли оцінюються за заголовками й ніколи не завантажуються повністю, тож посилання на архів чи відео не витрачає трафік.
