# Понад 500 правил, а нові пишуться як дані

- Правило — це шлях до факту плюс JSON Schema, тож нова перевірка не потребує коду.
- Вбудовані набори охоплюють пошук, заголовки безпеки, TLS, DNS, cookies, продуктивність, доступність, приватність, сталість, посилання, перенаправлення, карти сайту, robots.txt, файли well-known і файли для ШІ-агентів.
- Кожна група URL виконує власні набори правил, а серйозність будь-якого правила можна змінити або вимкнути з командного рядка, середовища чи projectfile.
- axe-core, html-validate і htmlhint працюють у тому самому обході, кожна їхня перевірка — правило, яке можна налаштувати чи вимкнути, як будь-яке інше, а оцінки Lighthouse додаються на відрендерених сторінках.
- Плагіни додають власні факти, правила, набори, формати звітів і джерела URL поряд із вбудованими, а простий список URL можна перевірити окремо.
