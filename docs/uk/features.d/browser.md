# Сторінки з клієнтським рендерингом перевіряються такими, якими їх бачать відвідувачі

- Сторінку, чиї теги, посилання чи вміст з’являються лише після виконання її скриптів, рендерить справжній браузер, тож перевіряється саме те, що бачать пошукові системи та відвідувачі.
- Рендеряться лише розділи, яким потрібен браузер; решта сайту обходиться звичайним HTTP на повній швидкості в тому самому запуску, а розділ, що рендерить свої теги на клієнті, можна виявити автоматично.
- Помилки консолі, час завантаження та кожен ресурс, який сторінка завантажує під час виконання, стають фактами, які можуть перевіряти правила.
- У звіт потрапляє те, що сторінка втрачає без JavaScript, — її заголовок, опис, канонічне посилання, заголовок першого рівня, внутрішні посилання чи текст, — за порівнянням її сирого HTML із відрендереною сторінкою.
