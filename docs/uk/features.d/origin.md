# Кожне джерело перевіряється один раз, окрім його сторінок

- Навмисно запитується неіснуюча сторінка, тож хибний 404 або сторінка помилки, що розкриває трасування стека чи версію сервера, — це знахідка.
- Кожен вхід — http чи https, з `www.` чи без, на головну чи вглиб сайту — має вести на одне канонічне джерело постійним перенаправленням, що зберігає шлях, а головна сторінка не повинна перенаправляти відвідувачів за їхньою мовою.
- Файли міждоменної політики, що дозволяють будь-якому іншому сайту читати сторінки із сесією відвідувача, стають знахідкою.
- Плагіни додають власні перевірки для кожного джерела чи хоста; їхні результати використовуються повторно між запусками, а їхні запити ніколи не залишають хост, який вони перевіряють.
