# Залежності сторінок завантажуються один раз

- Скрипти, таблиці стилів, зображення та фрейми, які завантажують сторінки, отримуються один раз за запуск, незалежно від їхнього походження.
- Зламана або небезпечна залежність — це одна знахідка зі списком сторінок, що її використовують, а не знахідка на кожну сторінку.
- Повідомляються скрипти з іншого походження без хешу цілісності та ресурси через звичайний HTTP на сторінках HTTPS.
- Маніфест вебзастосунку завантажується й оцінюється, як будь-яка інша залежність.
