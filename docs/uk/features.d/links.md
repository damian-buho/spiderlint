# Мертві посилання на сайті й поза ним

- Посилання, що нікуди не веде, на цей сайт чи на інший, — одна знахідка зі списком усіх сторінок, де воно є.
- Посилання на інші сайти перевіряються раз за запуск і запам’ятовуються на тиждень, тож повторний запуск нічого їм не надсилає.
- Сайт, який лише просить перевірку сповільнитися, не вважається мертвим.
