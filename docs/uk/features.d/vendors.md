# Те, що додає CDN чи хостинг, окремо

- Сторінки, які CDN чи хостинг віддає на сайті, як-от сторінка захисту пошти Cloudflare, не оцінюються як власні сторінки сайту, тож не знижують його оцінку.
- Скрипти, які вставляє CDN чи хостинг, і далі перевіряються, а їхні знахідки показано під постачальником, що їх віддає.
- Функцію, увімкнену в панелі CDN, яка чогось коштує відвідувачам, як-от адреси пошти, приховані від усіх без JavaScript, названо разом із налаштуванням, що її вимикає.
