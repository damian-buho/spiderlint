# Усі види сторінок одразу, яким би не був ліміт

- Сторінки відвідуються так, щоб кожен розділ сайту був охоплений вибіркою, перш ніж якийсь один вичерпається: перша сторінка проєкту завантажується раніше за п’ятдесяту публікацію.
- Ліміт сторінок чи обхід, перерваний достроково, усе одно показує кожен вид сторінок сайту.
- Вимикається одним налаштуванням, якщо потрібен порядок виявлення.
