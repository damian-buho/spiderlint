# Слід кожного перегляду сторінки

- Вуглецевий слід одного перегляду кожної сторінки оцінюється за байтами, які передають сторінка й усе, що вона завантажує, за моделлю Sustainable Web Design, а сторінки понад бюджет потрапляють у звіт.
- carbon.txt сайту має бути присутнім, коректним і актуальним, а розкриття, які він називає, — досяжними.
